# Whisper

This example runs Whisper with AMLNN. The full flow is:

1. Prepare or download the ONNX models.
2. Convert the ONNX models to ADLA models.
3. Run the Python demo with the ADLA models.
4. Run the C++ (Linux/Android) demo with the ADLA models.
5. Check audio transcription results.

## Directory Layout

```bash
examples/whisper/
├── cpp/               # C++ demo and build scripts
├── input/             # Input WAV audio files for demo
├── model/             # Put ONNX and ADLA models here
└── py/                # Python conversion and demo scripts
```

## 1. Prepare The ONNX Models

### Download ONNX

Download the prepared Whisper encoder and decoder ONNX models and tokenizer files:

### [Download Whisper Encoder ONNX model here!](https://pub-8378326bd0fe4b1d9312a3847f6316a2.r2.dev/model_zoo/whisper/whisper_encoder_static_sim.onnx)

### [Download Whisper Decoder ONNX model here!](https://pub-8378326bd0fe4b1d9312a3847f6316a2.r2.dev/model_zoo/whisper/whisper_decoder_static_sim.onnx)

### [Download Whisper Tokenizer zip here!](https://pub-8378326bd0fe4b1d9312a3847f6316a2.r2.dev/model_zoo/whisper/whisper_tokenizer.zip)

Place the downloaded ONNX models under:

```text
examples/whisper/model/whisper_encoder_static_sim.onnx
examples/whisper/model/whisper_decoder_static_sim.onnx
```

## 2. Convert ONNX To ADLA

Run the ADLA export script from `examples/whisper/py`:

```bash
cd examples/whisper/py
python export_adla.py \
  --encoder-onnx ../model/whisper_encoder_static_sim.onnx \
  --decoder-onnx ../model/whisper_decoder_static_sim.onnx \
  --target-platform 007 \
  --output-dir ../model
```

| Parameter           | Description                                                                                     |
| ------------------- | ----------------------------------------------------------------------------------------------- |
| `--encoder-onnx`    | Path to the Whisper encoder `.onnx` model.                                                      |
| `--decoder-onnx`    | Path to the Whisper decoder `.onnx` model.                                                      |
| `--target-platform` | Target platform ID. See the full list of supported platforms [**HERE**](../../docs/mapping.md). |
| `--output-dir`      | (Optional) Directory where the generated `.adla` models will be saved. Defaults to `../model`.  |

After conversion, the generated filenames from AMLNN are preserved. For the current `w8a16` with `activation_dtype="f16"` configuration, the expected model paths are:

```text
examples/whisper/model/whisper_encoder_static_sim_w8a16.adla
examples/whisper/model/whisper_decoder_static_sim_w8a16.adla
```

## 3. Run Python Demo

### Prerequisites

* Python 3.10
* Required packages: `amlnn`, `librosa`, `transformers`

### Install Dependencies

```bash
pip install amlnn_edge_toolkit_lite-1.0.0-cp310-cp310-linux_aarch64.whl librosa transformers
```

### Run on Device

```bash
python whisper_inference.py \
    --enc ../model/whisper_encoder_static_sim_w8a16.adla \
    --dec ../model/whisper_decoder_static_sim_w8a16.adla \
    --tokenizer ../tokenizer/ \
    --audio-file ../input/jfk.wav
```

Argument Descriptions:

| Argument               | Description                                |
| ---------------------- | ------------------------------------------ |
| `--enc` | Path to the Whisper encoder `.adla` model. |
| `--dec` | Path to the Whisper decoder `.adla` model. |
| `--tokenizer`      | Path to the Whisper tokenizer directory.   |
| `--audio-file`         | Path to the input `.wav` audio file.       |

The script processes the specified `.wav` audio file and prints the transcription to the console.

## 4. Run C++ Demo

### Build For Android

#### Prerequisites

* **Android NDK** (r25e recommended) installed on your system.
* **AMLNN Toolkit** downloaded and extracted.
* `ANDROID_NDK_PATH` environment variable set.

#### 1. Setup Environment

Export the paths to your NDK and AMLNN so the build script can find the required toolchain and neural network dependencies.

```bash
export ANDROID_NDK_PATH=/path/to/android-ndk-r25e
export AMLNN_HOME=/path/to/amlnn-toolkit
```

#### 2. Build

Navigate to the C++ directory and run the build script.

```bash
cd examples/whisper/cpp

# Build for 64-bit (arm64-v8a)
./build-android.sh -a arm64-v8a
```

The executable will be generated under:

```text
build/android/arm64-v8a/whisper_demo
```

#### 3. Example Run

The following example uses the 64-bit (`arm64-v8a`) build.

```bash
# Push executable and assets to device
adb shell "mkdir -p /data/local/tmp/"
adb push build/android/arm64-v8a/whisper_demo /data/local/tmp/
adb push ../model/whisper_encoder_static_sim_w8a16.adla /data/local/tmp/
adb push ../model/whisper_decoder_static_sim_w8a16.adla /data/local/tmp/
adb push ../cpp/data_bin /data/local/tmp/
adb push ../input/ /data/local/tmp/

# Run on device
adb shell
cd /data/local/tmp
chmod +x whisper_demo
export LD_LIBRARY_PATH=/vendor/lib64

# Usage: ./whisper_demo <encoder.adla> <decoder.adla> <audio.wav> <data_bin_dir>
# Set GET_TIME=1 before the command to print preprocessing, encoder, decoder, and total inference times.
# Set GET_OUTPUTS_SIZE=1 before the command to print the number of decoder inference calls.
GET_TIME=1 GET_OUTPUTS_SIZE=1 ./whisper_demo whisper_encoder_static_sim_w8a16.adla whisper_decoder_static_sim_w8a16.adla input/jfk.wav data_bin
```

> **Note:** Replace the ADLA filenames with your actual generated model filenames.

### Build For Linux

The Linux build process supports two distinct modes:

1. **Standard Linux cross-compilation** (default)
2. **Yocto SDK compilation**

#### Mode 1: Standard Linux Cross-Compile (Default)

##### Prerequisites

* A GCC Cross-Compiler toolchain (GCC 10.3 recommended).
* The toolchain's `bin/` folder must be added to your system's `PATH`.
* `AMLNN_HOME` environment variable set.

##### 1. Setup Environment

Add your downloaded toolchain to your `PATH` and export the `AMLNN_HOME` variable so the script can find the compiler and neural network dependencies.

```bash
# Export the AMLNN path
export AMLNN_HOME=/path/to/amlnn-toolkit

# For 64-bit (aarch64) builds, add the 64-bit toolchain to PATH:
export PATH=/path/to/gcc-arm-10.3-2021.07-x86_64-aarch64-none-linux-gnu/bin:$PATH

# OR for 32-bit (arm) builds, add the 32-bit toolchain to PATH:
export PATH=/path/to/gcc-arm-10.3-2021.07-x86_64-arm-none-linux-gnueabihf/bin:$PATH
```

##### 2. Build

```bash
cd examples/whisper/cpp

# Build for 64-bit (Default)
./build-linux.sh

# Build for 32-bit
./build-linux.sh -b 32
```

> **Optional Override:** If your compiler has a different prefix name, for example `aarch64-linux-gnu` instead of `aarch64-none-linux-gnu`, you can override the default by setting the `GCC_COMPILER` variable:

```bash
GCC_COMPILER=aarch64-linux-gnu ./build-linux.sh
```

The executable will be generated in the build folder corresponding to the selected architecture:

* 64-bit: `build/linux/64/whisper_demo`
* 32-bit: `build/linux/32/whisper_demo`

#### Mode 2: Yocto Build

##### 1. Prerequisites

* Yocto SDK installed.
* CMake Toolchain file available.
* Prebuilt OpenCV located at `../../../dependency/opencv/` (relative to the script directory).

##### 2. Setup Environment

```bash
# Export the AMLNN path
export AMLNN_HOME=/path/to/amlnn-toolkit
```

##### 3. Build

```bash
cd examples/whisper/cpp

# Build for Yocto 64-bit (Default)
./build-linux.sh -m yocto -s /path/to/yocto_sdk_root -t /path/to/toolchain.cmake

# Build for Yocto 32-bit
./build-linux.sh -m yocto -b 32 -s /path/to/yocto_sdk_root -t /path/to/toolchain.cmake
```

> **Note:** You can also use the `YOCTO_SDK_ROOT` and `TOOLCHAIN_FILE` environment variables instead of passing the `-s` and `-t` flags.

The executable will be generated in the build folder corresponding to the selected architecture:

* 64-bit: `build/yocto/64/whisper_demo`
* 32-bit: `build/yocto/32/whisper_demo`

#### 3. Example Run

The following example uses the default 64-bit Linux build.

```bash
# Push executable and assets to device (adjust build path if using Yocto)
adb shell "mkdir -p /data/local/tmp/"
adb push build/linux/64/whisper_demo /data/local/tmp/
adb push ../model/whisper_encoder_static_sim_w8a16.adla /data/local/tmp/
adb push ../model/whisper_decoder_static_sim_w8a16.adla /data/local/tmp/
adb push ../cpp/data_bin /data/local/tmp/
adb push ../input/ /data/local/tmp/

# Run on device
adb shell
cd /data/local/tmp
chmod +x whisper_demo

# Usage: ./whisper_demo <encoder.adla> <decoder.adla> <audio.wav> <data_bin_dir>
# Set GET_TIME=1 before the command to print preprocessing, encoder, decoder, and total inference times.
# Set GET_OUTPUTS_SIZE=1 before the command to print the number of decoder inference calls.
GET_TIME=1 GET_OUTPUTS_SIZE=1 ./whisper_demo whisper_encoder_static_sim_w8a16.adla whisper_decoder_static_sim_w8a16.adla input/jfk.wav data_bin
```

> **Note:** Replace the ADLA filenames with your actual generated model filenames. Adjust the executable path if using a 32-bit or Yocto build.
