# 量化数据集准备

## 数据集可用性与许可

本仓库仅包含项目维护者有权再分发的数据集或校准样本。

部分受支持的模型使用第三方数据集。由于这些数据集的许可证、使用条款或再分发条件不允许我们直接分发副本，它们**未包含**在本仓库中。文中提及这些数据集，仅用于说明模型可以如何校准或评估。

当第三方数据集被包含在本仓库中时：

* 它仍受其原始许可证和版权条款的约束。
* 覆盖本仓库的 Apache License 2.0 不会替代或推翻该数据集的原始许可证。
* 必须保留适用的第三方许可证与署名声明。

当数据集未被包含时，用户必须自行从官方发布渠道获取，并遵守所有适用的许可证条款、访问要求和使用限制。

用户有责任确保其对任何数据集的下载、使用、修改和再分发行为符合适用法律以及第三方知识产权的要求。


## 准备校准数据集

你可以通过以下任一方式准备量化校准数据集：

* 从官方来源获取受支持的公开数据集。
* 使用自己的代表性图像，对于特定部署场景的校准，推荐采用这种方式。

大约 **20 张代表性图像**通常足以完成基本的量化测试和演示。不过，合适的数量可能因模型、输入多样性、部署环境和所需精度而异。

为获得更好的量化精度，校准图像应尽量接近实际部署时预期的数据。

例如，请考虑以下方面：

* 光照条件
* 相机视角
* 图像分辨率
* 目标尺寸
* 背景
* 场景复杂度


## 准备图像

示例目录结构：

```text
resources/
├── detection_dataset/
│   ├── image001.jpg
│   ├── image002.jpg
│   ├── image003.jpg
│   └── ...
└── detection_dataset.txt
```

如果使用 COCO 2017 之类的公开数据集，请先从官方来源获取数据集，然后选取具有代表性的子集。

如果图像仅用于量化校准，则无需包含标注，除非特定转换工具要求提供标注。


## 配置数据集列表

每个数据集配置文件必须**每行一个图像路径**。

示例 `detection_dataset.txt`：

```text
./detection_dataset/image001.jpg
./detection_dataset/image002.jpg
./detection_dataset/image003.jpg
```

每一行应指向一张校准图像。

使用自己的数据集时，请将示例条目替换为你的图像路径。

推荐使用相对路径，因为这样配置在不同系统和仓库位置之间更具可移植性。

## 模型与数据集配置

下表将每种数据集类型映射到对应的数据集列表文件。

| 目标数据集          | 数据集列表文件               | 本仓库是否包含              |
| :------------------ | :--------------------------- | :-------------------------  |
| COCO 2017           | `detection_dataset.txt`      |              否             |
| COCO 2017 Keypoints | `pose_dataset.txt`           |              否             |
| ImageNet 2012       | `classification_dataset.txt` |              否             |
| Total-Text          | `sign_dataset.txt`           |             是              |
| 自定义字体数据集    | `font_dataset.txt`           |             是              |

只有标记为已包含的数据集才由本仓库再分发。未包含的数据集对应的配置文件仅用于展示预期的路径格式，并不授予对这些数据集的访问权或再分发权。

## 注意事项

* 使用能代表预期部署输入的校准图像。
* 大约 20 张图像可能足以完成初步测试，但增加多样性有助于提升校准质量。
* 确保数据集列表文件中的每个路径都存在且可读。
* 每行使用一个图像路径。
* 为便于移植，推荐使用相对路径。
* 不要认为本仓库的 Apache License 2.0 适用于第三方数据集。
* 保留所有必需的第三方版权、署名和许可证声明。
* 下载或再分发数据集之前，请查阅数据集官方来源以获取最新的许可证条款。
