# SigLIP2

This example runs SigLIP2 with AMLNN. The full flow is:

1. Prepare or download the ONNX models.
2. Convert the ONNX models to ADLA models.
3. Run the Python demo with the ADLA models.
4. Run the C++ (Linux/Android) demo with the ADLA models.
5. Check the image-text matching results.

## Directory Layout

```bash
examples/siglipv2/
├── cpp/                 # C++ demo and build scripts
├── input/               # Input images for demo
├── model/               # Put ONNX and ADLA models here
├── py/                  # Python conversion and demo scripts
└── tokenizer/           # SigLIP2 tokenizer directory
```

## 1. Prepare The ONNX Models

### Download Models

Download the prepared models and tokenizer:

### [Text encoder ONNX model](https://pub-8378326bd0fe4b1d9312a3847f6316a2.r2.dev/model_zoo/siglipv2/siglip2_text_encoder_sim.onnx)
### [Image encoder ONNX model](https://pub-8378326bd0fe4b1d9312a3847f6316a2.r2.dev/model_zoo/siglipv2/siglip2_vision_encoder_sim.onnx)
### [Siglipv2 Tokenizer zip](https://pub-8378326bd0fe4b1d9312a3847f6316a2.r2.dev/model_zoo/siglipv2/siglip_tokenizer.zip)

Place the ONNX models under `examples/siglipv2/model/` and extract the tokenizer under `examples/siglipv2/tokenizer/`.

Expected paths:

```text
examples/siglipv2/model/siglip2_text_encoder_sim.onnx
examples/siglipv2/model/siglip2_vision_encoder_sim.onnx
examples/siglipv2/tokenizer/
```

## 2. Convert ONNX To ADLA

Run the ADLA export script from `examples/siglipv2/py`:

```bash
cd examples/siglipv2/py
python export_adla.py \
    --text-onnx ../model/siglip2_text_encoder_sim.onnx \
    --image-onnx ../model/siglip2_vision_encoder_sim.onnx \
    --target-platform 007 \
    --output-dir ../model
```

| Parameter              | Description                                                                                                |
| ---------------------- | ---------------------------------------------------------------------------------------------------------- |
| `--text-onnx`          | Path to the text encoder `.onnx` model.                                                                    |
| `--image-onnx`         | Path to the image encoder `.onnx` model.                                                                   |
| `--text-dataset-path`  | (Optional) Path to a `.txt` file containing the input paths used for text model quantization calibration.  |
| `--image-dataset-path` | (Optional) Path to a `.txt` file containing the input paths used for image model quantization calibration. |
| `--target-platform`    | Target platform ID. See the full list of supported platforms [**HERE**](../../docs/mapping.md).            |
| `--output-dir`         | (Optional) Directory where the generated `.adla` models will be saved. Defaults to `../model`.             |

> **Quantization dataset note**
>
> A calibration dataset is not required when using `activation_dtype="f16"`, such as `w8a16 (f16)` or `w16a16 (f16)`.
>
> If no dataset is provided for a quantization mode that requires calibration, AMLNN generates random calibration data instead of failing, which can severely degrade model accuracy.

With the generated models, the expected paths will be similar to:

```text
examples/siglipv2/model/siglip2_text_encoder_sim.adla
examples/siglipv2/model/siglip2_vision_encoder_sim.adla
```

## 3. Run Python Demo

### Prerequisites

* Python 3.10
* Required packages: `numpy`, `opencv-python`, `amlnn`

### Install Dependencies

```bash
pip install numpy opencv-python amlnn_edge_toolkit-1.0.0-cp310-cp310-linux_aarch64.whl
```

### Run on Device

The SigLIP2 Python demo accepts candidate labels with `--prompt` and applies the prompt template specified by `--prompt-template`.

```bash
python siglipv2_inference.py \
    --vision ../model/siglip2_vision_encoder_sim.adla \
    --text ../model/siglip2_text_encoder_sim.adla \
    --tokenizer ../tokenizer/ \
    --image-dir ../input \
    --prompt "red bus" "blue car" "person" "dog"
```

Argument Descriptions:

| Argument            | Description                                                            |
| ------------------- | ---------------------------------------------------------------------- |
| `--vision`          | Path to the vision encoder `.adla` model.                              |
| `--text`            | Path to the text encoder `.adla` model.                                |
| `--tokenizer`   | Directory containing the SigLIP2 tokenizer files.                      |
| `--image-dir`       | Directory containing the test images.                                  |
| `--prompt`          | Candidate labels to compare against each image.                        |
| `--prompt-template` | (Optional) Prompt template containing `{}`. Defaults to `This is a photo of {}.`. |
| `--top-k`           | (Optional) Number of results to print. Defaults to `5`.                           |

The script processes the images in the specified image directory and prints the highest-ranked image-text matches.

## 4. Run C++ Demo

### Build For Android

#### Prerequisites

* **Android NDK** (r27d recommended) installed on your system.
* **AMLNN Toolkit** downloaded and extracted.

#### 1. Setup Environment

Export the paths to your NDK and AMLNN so the build script can find the required toolchain and neural network dependencies.

```bash
export ANDROID_NDK_PATH=/path/to/android-ndk-r27d
export AMLNN_HOME=/path/to/amlnn-toolkit/amlnn_runtime
```

#### 2. Build

Navigate to the C++ directory and run the build script.

```bash
cd examples/siglipv2/cpp

# Build for 64-bit (arm64-v8a) - Default
./build-android.sh

# Build for 32-bit (armeabi-v7a)
./build-android.sh -a armeabi-v7a
```

The executable will be generated in the build folder corresponding to the selected Android ABI.

* 64-bit: `build/android/arm64-v8a/siglipv2_demo`
* 32-bit: `build/android/armeabi-v7a/siglipv2_demo`

#### 3. Example Run

The C++ executable accepts the vision model, text model, tokenizer directory, image directory, and candidate texts.

```bash
# Push executable and assets to device
adb shell "mkdir -p /data/local/tmp/"
adb push build/android/arm64-v8a/siglipv2_demo /data/local/tmp/
adb push ../model/siglip2_vision_encoder_sim.adla /data/local/tmp/
adb push ../model/siglip2_text_encoder_sim.adla /data/local/tmp/
adb push data_bin/ /data/local/tmp/
adb push ../input /data/local/tmp/

# Run on device
adb shell
cd /data/local/tmp
chmod +x siglipv2_demo
export LD_LIBRARY_PATH=/vendor/lib64

# Usage:
# ./siglipv2_demo <vision_model.adla> <text_model.adla> <data_bin> <image_dir> [texts ...]
./siglipv2_demo \
    siglip2_vision_encoder_sim.adla \
    siglip2_text_encoder_sim.adla \
    ./data_bin \
    ../input/ \
    "a red handbag" \
    "a blue jacket" \
    "a red bus"
```
> **Note:** To generate data_bin, there is a provided compile_tokenizer.py in the `siglipv2/py/` directory.

> **Note:** For a 32-bit (`armeabi-v7a`) build, use `build/android/armeabi-v7a/siglipv2_demo` and the corresponding 32-bit library path. Replace the `.adla` model filenames with your actual generated model filenames.

### Build For Linux

The Linux build process supports two distinct modes:

1. **Standard Linux cross-compilation** (default)
2. **Yocto SDK compilation**

#### Mode 1: Standard Linux Cross-Compile (Default)

##### Prerequisites

* A GCC Cross-Compiler toolchain (GCC 10.3 recommended).
* The toolchain's `bin/` folder must be added to your system's `PATH`.
* `AMLNN_HOME` environment variable set.

##### 1. Setup Environment

```bash
# Export the AMLNN path
export AMLNN_HOME=/path/to/amlnn-toolkit/amlnn_runtime

# For 64-bit (aarch64) builds, add the 64-bit toolchain to PATH:
export PATH=/path/to/gcc-arm-10.3-2021.07-x86_64-aarch64-none-linux-gnu/bin:$PATH

# OR for 32-bit (arm) builds, add the 32-bit toolchain to PATH:
export PATH=/path/to/gcc-arm-10.3-2021.07-x86_64-arm-none-linux-gnueabihf/bin:$PATH
```

##### 2. Build

```bash
cd examples/siglipv2/cpp

# Build for 64-bit (Default)
./build-linux.sh

# Build for 32-bit
./build-linux.sh -b 32
```

The executable will be generated in the build folder corresponding to the selected architecture:

* 64-bit: `build/linux/64/siglipv2_demo`
* 32-bit: `build/linux/32/siglipv2_demo`

##### Optional Override

If your compiler has a different prefix name, you can override the default by setting the `GCC_COMPILER` variable:

```bash
GCC_COMPILER=aarch64-linux-gnu ./build-linux.sh
```

#### Mode 2: Yocto/Debian/Armbian Build

##### 1. Prerequisites

* Yocto SDK installed.
* CMake Toolchain file available.

##### 2. Setup Environment

```bash
# Export the AMLNN path
export AMLNN_HOME=/path/to/amlnn-toolkit/amlnn_runtime
```

##### 3. Build

```bash
cd examples/siglipv2/cpp

# Build for Yocto 64-bit (Default)
./build-linux.sh -m yocto -s /path/to/yocto_sdk_root -t /path/to/toolchain.cmake

# Build for Yocto 32-bit
./build-linux.sh -m yocto -b 32 -s /path/to/yocto_sdk_root -t /path/to/toolchain.cmake
```

> **Note:** You can also use the `YOCTO_SDK_ROOT` and `TOOLCHAIN_FILE` environment variables instead of passing the `-s` and `-t` flags.

The executable will be generated in the build folder corresponding to the selected architecture:

* 64-bit: `build/yocto/64/siglipv2_demo`
* 32-bit: `build/yocto/32/siglipv2_demo`

#### Example Run

    siglip2_vision_encoder_sim.adla \
    siglip2_text_encoder_sim.adla \
    ./data_bin \
    ../input/ \

> **Note:** To generate data_bin, there is a provided compile_tokenizer.py in the `siglipv2/py/` directory.

> **Note:** Replace the `.adla` model filenames with your actual generated model filenames. Adjust the executable path if using a 32-bit or Yocto build.

## 5. Results

### Performance Feedback

By setting the log level to `INFO`, the program provides runtime performance information after inference. The console output may include:

* **Hardware Information:** System and ADLA library versions.
* **Model Overview:** Input and output tensor configurations.
* **NPU Metrics:** Inference latency and DRAM bandwidth usage.

### Image-Text Matching Output

For each input image, the demo compares the image embedding against the supplied text prompts and prints the matching results ranked by score.

Example:

```text
============================================================
Processing image 1/4: apples.jpg
============================================================
    [1] apple: probability=0.162227, logit=-1.641751
    [2] a red handbag: probability=0.000022, logit=-10.720261
    [3] children: probability=0.000011, logit=-11.396953
    [4] dog: probability=0.000004, logit=-12.357706
    [5] elephant: probability=0.000001, logit=-13.892324
    Result saved to: siglip2_vision_encoder_sim_result/apples_result.txt
============================================================
```

The result shows the image-text matching scores for the supplied prompts, ordered from the highest-scoring match to the lowest.
